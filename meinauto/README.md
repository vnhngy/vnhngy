# Mein Auto – iPhone-Version

Persönliche Auto-Startseite als Web-App (gleiche Oberfläche wie die Android-App auf dem Tablet).

- Adresse: `https://vnhngy.github.io/vnhngy/meinauto/`
- Aufs iPhone: Link in **Safari** öffnen → **Teilen** → **„Zum Home-Bildschirm“**
- Daten bleiben nur auf dem jeweiligen Gerät. Übertragen: auf dem Tablet „Sicherung teilen“,
  auf dem iPhone unter Anpassen → App → „Aus Datei wiederherstellen“.
- Nur in der Android-App: Widget, Preis-Alarm im Hintergrund, Erinnerungen, Bluetooth-Start.

Dateien: `index.html` (alles in einer Datei), `manifest.webmanifest` + Icons (Home-Bildschirm),
`sw.js` (Offline-Speicher).
